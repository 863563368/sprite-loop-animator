# 别让角色只停在立绘里：一张图做动画，也能做动图表情

角色画好了，接下来呢？

可以让它原地跑起来，做一组游戏里的跑步动画；也可以让它眨眨眼、挥挥手，变成聊天时能发的动图表情。哪怕只是小猫趴在窗边甩尾巴，一个简单的小场景，动起来也会有趣很多。

**sprite-loop-animator** 就是用来做这些小动画的。给它一张参考图，再说清楚想要的动作，它会生成视频，并整理出 GIF、精灵图和逐帧 PNG。

**关键是让角色“在原地动”。**

直接生成视频，角色可能会越跑越远，镜头也可能跟着移动。看视频时没什么问题，抽成动画帧后，却很难直接使用。

所以这套流程会用参考图固定角色造型，并尽量让角色的位置、大小和镜头保持稳定。腿可以跑，手可以挥，头发可以晃，但角色始终待在画面里的同一个地方。

使用时，不用写复杂的提示词。给出图片，再说一句：

> 让这个角色原地向右跑，做成循环动画，输出透明背景 GIF 和精灵图。

想做表情，就把动作换成“眨眼微笑”“轻轻挥手”；想做小场景，可以试试“坐在桌边晃腿”“趴在窗边甩尾巴”这类幅度不大的动作。

最后拿到的素材也不只有一张动图：

- **GIF**：方便预览、分享或做表情；
- **精灵图**：适合放进游戏项目；
- **逐帧 PNG**：方便挑帧和继续修改；
- **动画视频**：保留生成的原始版本。

生成后记得播放看一遍：角色有没有走形，循环接起来是否自然；如果画面里有道具，也看看去背景时有没有被误删。

有时，一个角色不需要大段剧情。让它跑两步、眨一下眼，就已经比静静待在画布上生动许多。
